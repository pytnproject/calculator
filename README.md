# Simple Python Calculator

A command-line calculator written in Python. The application runs in a continuous loop, performs basic arithmetic operations (addition, subtraction, multiplication, division), and includes error handling for invalid inputs (non-numeric values) and division by zero.

## Features
*   **Basic Operations:** Addition, subtraction, multiplication, and division.
*   **Robust Error Handling:** Catches `ValueError` if the user enters text instead of numbers.
*   **Zero Division Protection:** Safely handles attempts to divide by zero.
*   **Continuous Loop:** Allows the user to perform multiple calculations without restarting the program.

## How to Run

1. Ensure you have Python 3.x installed.
2. Clone the repository or download the script:
 ```
 git clone https://github.com/pytnproject/calculator.git
 ```

3. Navigate to the project folder:
   ```
   cd calculator
   ```
4. Run the script:
   ```
   python script.py
   ```
